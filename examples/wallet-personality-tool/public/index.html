Wallet Personality

An ERC-8257 agent tool that turns a wallet's onchain history into a markdown personality file.

Reference implementation. This deploy is a worked example shipped alongside @opensea/tool-sdk. Fork the code to run your own tool; this endpoint is illustrative, not a production service, and may change or go offline without notice.

Manifests

GET /.well-known/ai-tool/wallet-personality.json
GET /.well-known/ai-tool/wallet-personality-subscriber.json

Public tier

POST to /api with an x402 payment ($0.05 USDC on Base):

{ "targetAddress": "0x..." }

Subscriber tier

POST to /api/subscriber with a SIWE auth header from a wallet that holds an active subscription NFT on Base. Free for subscribers; non-holders get a clean 403.

Powered by @opensea/tool-sdk + ERC-8257 ToolRegistry + Anthropic Claude.
