NFT Appraiser

An ERC-8257 agent tool for NFT price appraisals. Paid via x402 (USDC on Base).

Reference implementation. This deploy is a worked example shipped alongside @opensea/tool-sdk. Fork the code to run your own tool; this endpoint is illustrative, not a production service, and may change or go offline without notice.

Calling the tool

POST to the endpoint with a JSON body:

{
  "chain": "ethereum",
  "contractAddress": "0x...",
  "tokenId": "..."
}

Without payment, the response is an x402-compliant 402 with PaymentRequirements. With a valid signed payment (and SIWE auth on the holder route), the response is a structured appraisal: low / mid / high range, confidence, reasoning, recent sales, and comparable listings.
