Token + NFT Holder Overlap

A free, predicate-gated ERC-8257 agent tool. Finds wallets holding both an ERC-20 token and NFTs from a collection.

Reference implementation. This deploy is a worked example shipped alongside @opensea/tool-sdk. Fork the code to run your own tool; this endpoint is illustrative, not a production service, and may change or go offline without notice.

Manifest

GET /.well-known/ai-tool/token-nft-overlap.json

Calling the tool

POST to /api with a JSON body:

{
  "tokenAddress": "0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48",
  "collectionSlug": "boredapeyachtclub",
  "chain": "ethereum",
  "maxPages": 5
}

Without valid EIP-3009 auth proving NFT ownership, the response is HTTP 403. With valid auth, the response is a structured overlap report ranked by token USD value.

Powered by @opensea/tool-sdk + the OpenSea v2 REST API. No LLM required.
